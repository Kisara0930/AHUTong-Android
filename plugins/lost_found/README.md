# 失物招领插件

包含列表、失物/招领切换、校区/类型筛选、分页、图片详情、发布、我的帖子和删除。协议路径、JSON 字段与表单字段沿用原 ADWMH 接口；账户插件仅提供智慧安大会话能力。

写入使用一次性 request body，禁重定向和传输重试，不因鉴权失效自动重放。服务器未确认的写入提示先刷新“我的帖子”。只有读操作允许一次会话续期。账号代数绑定到页面仓储与缓存，切换账号或停用后旧请求不能更新新账号数据；释放页面只取消本组件持有的网络 Call。

缓存复制到 `plugin_lost_found.<userBox>.*` 加密命名空间，读取旧加密值、原生快照或对应账号旧 MMKV 作为迁移来源，不删除旧数据。个性化仅使用可选 `BehaviorRecorder` / `PresetSuggestions`；不携带助手实现，未安装助手时不采集。

新增 MockWebServer 契约测试覆盖分页字段、一次读续期、写入不重放、投递确认丢失与账号变化前阻止请求。测试只请求本地 fixture 服务，不发布或删除真实帖子。
