# 校园通知插件

保留安徽大学官网与研究生院两种来源、分页历史锚点、按账号加密缓存、已读状态、七天自动已读、新公告提醒和首页未读角标。研究生账号额外启用研究生院来源，身份来自共享 SessionStore。

启用/进入前台时请求原有“一天一次”的同步；重复触发合并，停用或进入后台取消本次同步。没有定时轮询。加密箱 `notice_user_*` 与 `campus_notices_v1` 沿用原规则，停用不清空文章和已读记录。

研究生院网页渲染保留单独 `:postgraduate_notices` 进程与独立 WebView 数据目录。宿主仅提供受限 UID 的通用 Provider 代理；插件保留受信任栏目校验、JS 提取、超时和页面大小限制，不导入其他网页的 Cookie。

通知通过宿主调度器发送，route 带 account/article/url。插件打开通知前必须与当前账号缓存和可信 URL 再次匹配，不能直接执行通知中的链接。首页布局通过 `PluginHomeCardManager` 调整。原来源解析、分页、缓存与同步契约测试已迁入模块。
